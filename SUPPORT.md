# Support Guidelines

We are dedicated to helping developers succeed with Tynx. Please review the available channels below to find help:

---

## 1. Documentation & Guides
Before opening an issue, check the official documentation:
* [Quickstart Guide](https://tynx.dev/docs)
* [Installation & Verification](https://tynx.dev/download)
* [Troubleshooting Hub](https://tynx.dev/docs/troubleshooting)
* [Interactive Playground](https://tynx.dev/playground)

---

## 2. Public Bug Reports & CLI Problems
If you encounter a reproducible compiler crash, lowering mismatch, CLI execution bug, or documentation error:
* [Open a Bug Report](https://github.com/tynx-lang/tynx-releases/issues/new?template=bug_report.yml)
* [Report an Installation Problem](https://github.com/tynx-lang/tynx-releases/issues/new?template=installation_problem.yml)

---

## 3. Confidential / Private Compiler Diagnostics
If you encounter a compiler lowering bug on proprietary code that cannot be shared publicly:
* Use the **Send private feedback** option directly inside the [Web Playground](https://tynx.dev/playground).
* Or visit [https://tynx.dev/feedback](https://tynx.dev/feedback).
* Source code upload is strictly opt-in and confidential.

---

## 4. Security Reports
For security-related disclosures, see [SECURITY.md](./SECURITY.md).
